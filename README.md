# 🕷️ Spider-Man Movies – Power BI Dashboard

## 📌 Project Overview

This project presents an interactive **Spider-Man Movies Dashboard** created using Microsoft Power BI.

The dashboard provides an overview of Spider-Man movies through visually appealing tables, and information cards. It allows users to explore movie details, including release year, movie title, director, runtime, cast, storyline, and movie series.

The dashboard combines data visualization with a Spider-Man-inspired design to make movie exploration more engaging.

## 🎯 Project Objectives

- Explore Spider-Man movies across different years.
- Display movie titles and directors.
- Present movie information in an interactive dashboard.
- Analyze movie runtime and release types.
- Showcase cast members and movie storylines.
- Create an attractive and user-friendly Power BI dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data preparation and transformation.
- **DAX** – Data calculations and measures.
- **Data Visualization** – Interactive tables, cards, and filters.

## 📊 Dashboard Features

### 1. Movie Overview
- Displays the movie count.
- Provides a movie category overview.
- Includes a Live Action selection.

### 2. Movie Details
Displays information such as:
- Movie title
- Release year
- Director
- Release type
- Runtime
- Storyline
- Cast members
- Movie series
